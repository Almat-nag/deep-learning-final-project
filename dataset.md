# Dataset Information

We used the Jigsaw Toxic Comment Classification dataset.

The dataset contains user-generated comments from online platforms.
Each comment is labeled according to different types of toxic behavior.

Dataset size: 159,571 comments
Input feature: raw text comment
Task type: multi-label text classification
Number of labels: 6

Labels:
toxic — general toxic language
severe_toxic — highly abusive language
obscene — vulgar or inappropriate language
threat — threatening language
insult — insulting or humiliating language
identity_hate — hate speech based on identity

One comment can have more than one label at the same time.
For example, a comment can be both toxic and insult.
